# MazeQuest Mini UI Reference

`mazequest-ui-reference.png` is the visual direction for the first playable release.

## Screen 1 — Start menu

- Large readable MazeQuest Mini title.
- Friendly explorer preview.
- Short description.
- Primary Start Adventure button.
- Secondary How to Play button.
- Bright cartoon-fantasy environment.

## Screen 2 — Level interface

- Top-down maze remains the primary visual focus.
- Compact HUD with hearts, crystal counter, key inventory, objective, Pause, and Restart.
- On-screen directional controls.
- Visually distinct key, door, switch, bridge, lever, traps, crystals, chest, and exit portal.

## Implementation note

Use the mockup as a reference for style, hierarchy, color, and interface composition. Do not copy its maze layout literally. The implemented level must follow the mechanics and acceptance criteria in `PRD.md`, including three required puzzles and a fully valid playable route.
